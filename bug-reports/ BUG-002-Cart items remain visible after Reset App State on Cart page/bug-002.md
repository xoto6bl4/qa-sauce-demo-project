## Summary
Cart items remain visible on the Cart page after using **Reset App State**, even though the cart badge is cleared.

## Environment
- Website: https://www.saucedemo.com/cart.html
- Browser: Chrome
- User: standard_user / any valid user
- Page: Cart page

## Preconditions
- User is logged in.
- At least one product is added to the cart.
- User is on the Cart page.

## Steps to Reproduce
1. Add one or more products to the cart.
2. Navigate to the Cart page.
3. Open the burger menu.
4. Click **Reset App State**.
5. Observe the shopping cart badge.
6. Observe the cart item list without refreshing the page.

## Expected Result
- The cart badge is removed or no longer displays an item count.
- The cart item list becomes empty immediately.
- No previously added products remain visible on the Cart page.

## Actual Result
- The cart badge is removed.
- Previously added cart items remain visible on the Cart page.
- Cart items disappear only after page refresh or navigation.

## Severity
Major

## Priority
High

## Type
Functional
